# DatosPBA2.0

Sitio de análisis político y datos abiertos sobre la Provincia de Buenos Aires (ver `CLAUDE_WEB.md` para el mapa del sitio). Sin relación con Cruz Roja Argentina ni el Observatorio Humanitario.

## Sistema de diseño

Este repo tiene su propio sistema de diseño (`.claude/skills/design-system-datospba/`, `.claude/skills/graficos-datospba/`). **Nunca uses el skill `cruz-roja-argentina-design`** (identidad de Cruz Roja Argentina / Observatorio Humanitario) en este repo, aunque esté disponible a nivel usuario — no aplica acá bajo ninguna circunstancia.
